
                                Omni AI Terminal

Локальный AI-терминал для Windows с поддержкой PowerShell, SSH, плагинов
и интеллектуального анализа ошибок

Версия: 1.1.0
Python: 3.14+
Лицензия: Apache 2.0


О проекте


Omni — это терминал нового поколения, объединяющий мощь классической командной
строки с возможностями локального искусственного интеллекта. Программа работает
полностью на вашем компьютере, не требуя подключения к интернету или отправки
данных на внешние серверы.

В основе Omni лежит языковая модель Mistral-7B, которая понимает запросы на
естественном русском языке и самостоятельно генерирует исполняемые команды
PowerShell.


Возможности


Интеллектуальные команды    - AI понимает русский язык, преобразует запросы
                              в PowerShell команды

Интерактивный терминал      - Полноценная работа с PowerShell, поддержка SSH,
                              Python, системных редакторов

SSH Manager                 - Управление удалёнными подключениями, сохранение
                              конфигураций, встроенный терминал

Генерация скриптов          - AI создаёт готовые .ps1 и .bat скрипты под вашу
                              задачу

Анализ ошибок               - Вставьте сообщение об ошибке — AI объяснит
                              причину и предложит решение

Система плагинов            - Превращайте собственные скрипты в плагины с
                              удобным запуском из интерфейса

Оформление                  - Пять цветовых тем: тёмная, светлая, фиолетовая,
                              зелёная, синяя

Надёжность                  - Механизм перехвата ошибок гарантирует стабильную
                              работу программы


Системные требования


Windows 10 / 11
8 ГБ оперативной памяти (рекомендуется 16 ГБ)
5 ГБ свободного дискового пространства


Установка


Из исходных кодов:

    git clone https://github.com/ilabolAfk/OmniTerminal
    cd omni
    pip install PyQt5 ctransformers
    python main.py

Готовая сборка:

    Скачайте последний релиз с GitHub и запустите Omni.exe.
    положите модель в %APPDATA%\Omni\mistral-7b-instruct-v0.3.Q4_K_M.gguf
    AI-модель загрузится автоматически при первом запросе.

Плагины
<img width="601" height="488" alt="plugins" src="https://github.com/user-attachments/assets/532eb016-b4c1-4766-9867-5c8b5c01b69f" />


Omni поддерживает расширение функциональности через плагины. Плагин представляет
собой папку с двумя файлами:

manifest.json
------------
{
    "name": "Название плагина",
    "version": "1.0",
    "description": "Краткое описание",
    "author": "Автор",
    "command": "powershell -File script.ps1"
}

script.ps1
----------
(исполняемый PowerShell скрипт)

run.bat файл запуска (опционально)
----------
Установка выполняется через интерфейс программы:
    «Плагины» → «Установить из папки»
